# Report

Final reports use the **IEEE conference format**.

- Overleaf (recommended): start from the IEEE Conference template and share the read link in your submission.
- Or place your `.tex` / `.bib` here and build locally.

## Required sections (see the project handout)

Cover page (title + team) · Abstract · Introduction · Literature review ·
Implementation (approach, datasets) · Data analysis & performance discussion ·
Conclusion (lessons learned, future work) · References · Appendix (code pointers).

Put final figures from `../results/` here (or `\includegraphics` them directly).
